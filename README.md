# Домашние задания по Python

Репозиторий с домашними заданиями по курсу Python Basic Академии Авито.

Для запуска нужен Python3. Сторонних зависимостей нет.

## Запуск

Выполняйте команды из корневого каталога репозитория `omd`.
Каждый файл запускается отдельно:

```bash
python3 HW_1/task1.py
python3 HW_1/task2.py
python3 HW_1/task3.py
python3 HW_1/task4.py
python3 HW_1/task5.py
```
