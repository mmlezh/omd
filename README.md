# Домашние задания по Python

Для запуска нужен Python 3.6 или новее. Сторонних зависимостей нет. Устанавливать дополнительные пакеты для запуска программы не требуется.

## Запуск HW2

Перейдите в папку `HW_2` и запустите программу.

```bash
python3 hw_functions.py
```

После запуска введите номер отчёта и нажмите Enter:

1. Показать команды каждого департамента.
2. Показать численность сотрудников, минимальный, максимальный и средний оклад.
3. Сохранить такую же сводку в `department_summary.csv`.

Программа читает `Corp_Summary.csv` из текущей папки терминала, поэтому запускайте её из `HW_2`. Выходной файл создаётся там же.

Повторный запуск варианта 3 перезаписывает его.
CSV-файлы используют кодировку UTF-8 и разделитель `;`.
